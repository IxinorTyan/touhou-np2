# 东方旧作 · NP2 浏览器版

双击 **start.bat**，浏览器会自动打开游戏选择页。选择作品和语言，再点“启动游戏”。默认地址是 http://127.0.0.1:9861/ ，端口被占用时自动尝试后续端口，请以启动窗口中的地址为准。

保留 BAT 打开的窗口；关闭窗口或按 Ctrl+C 可停止网页服务。启动需要 Python 3（本机已安装），运行游戏推荐新版 Edge / Chrome。所有内核、字体和游戏镜像都已放在本目录，启动不需要外网，也不需要 npm 或编译工具。

## 游戏与操作

- 东方灵异传：日文原版。
- 东方封魔录、梦时空、幻想乡、怪绮谈：日文 / 中文版本。
- 方向键移动，Z 确认或射击，X 炸弹，Esc 暂停；以各游戏实际操作为准。
- 请切换英文输入法。点击画面激活键盘和声音。
- 支持网页暂停、重启、全屏，以及 CPU 频率选择（启动前设置）。

## 存档

游戏实际写入硬盘的成绩和设置会自动保存到浏览器 IndexedDB；不包含即时存档。关闭页面前请等待“已保存”。每部作品、每种语言都有独立镜像及存档键，共 9 个镜像，各作品互不覆盖。

“导出硬盘备份”下载当前作品的 HDI；在启动游戏之前，可以用“导入备份”恢复同作品、同语言备份。旧版共享磁盘存档会在当前作品首次启动时自动迁移，旧存档保留；也可导入旧版同语言备份，自动提取当前作品。更换浏览器、端口或清理站点数据后，需重新导入备份。避免同时打开同一作品、同一语言的多个页面，以免覆盖存档。

## 实现

- 内核：irori/np2-wasm 的 NP21（Neko Project II 系列 PC-9821 / i386 版本）。原镜像的 CONFIG.SYS 使用 VEM486，故默认使用支持 386 的 NP21。
- 9 个独立 HDI 以 gzip 保存，按作品和语言按需加载，并验证 SHA-256。每个镜像只保留当前作品及必要启动文件，其他作品的文件和数据簇已移除；保留原磁盘容量作为存档空间。打包时清零 FAT12 明确标为空闲的簇，避免历史残留增大压缩包；不改动有效文件与已分配簇。
- 梦时空单独设置 NP2 的 DIP 2-8（DIPswtch 第二字节为 0xf3），使用 GDC 2.5 MHz 模式，避免游戏切换显示模式后恢复成 5 MHz。CPU 倍频与 GDC 时钟独立。
- 浏览器仅在镜像的内存副本中修改 AUTOEXEC.BAT，进入对应目录执行原有 GAME.BAT。原始整合包不被改写。
- 启动脚本提供仅监听 127.0.0.1 的本地静态 HTTP 服务；CPU、画面和声音由浏览器中的 WebAssembly 处理。
